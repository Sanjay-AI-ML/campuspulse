🎓 CampusPulse

Smart Campus & Exam Issue Reporting & Resolution Tracker

Empower Your Campus Community

CampusPulse is an AI-powered platform that enables college students to report campus and exam issues, track resolutions in real-time, and engage with their institution transparently.

Whether it's faulty WiFi, seating arrangements, or maintenance concerns—CampusPulse ensures your voice is heard.

🌟 Key Features

📋 Dual-Track Reporting

Report campus issues (WiFi, plumbing, safety) or exam issues (seating, tickets, results) with full categorization and priority levels.

🤖 AI Resolution Assistant

Get AI-generated insights and resolutions powered by OpenAI, Groq, or Gemini. Degradable—works with or without AI.

📊 Real-time Tracking

Track issue status from submission through resolution. Filter by category, status, priority, and search keywords.

👥 Role-Based Access

Students report and track their own issues. Admins manage all issues, update status, and assign priorities.

📸 Photo Upload

Attach evidence photos to strengthen issue reports and provide clear context to administrators.

🔍 Smart Search

Search across issue titles, descriptions, locations, and reporter names. Find similar issues automatically.

🚀 Quick Start

1. Clone & Install

git clone https://github.com/Sanjay-AI-ML/campuspulse.git
cd campuspulse
pip install -r requirements.txt

2. Configure Environment

cp .env.example .env
# Edit .env with your API keys (optional—AI features degrade gracefully)

3. Run Application

python backend/app.py
# Open http://localhost:5001 in your browser

4. Demo Credentials

  • Student: username=student, password=student123
  • Admin: username=admin, password=admin123
